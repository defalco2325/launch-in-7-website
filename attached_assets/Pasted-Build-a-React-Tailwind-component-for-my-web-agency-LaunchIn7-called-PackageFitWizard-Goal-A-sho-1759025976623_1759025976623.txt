Build a React + Tailwind component for my web agency LaunchIn7 called PackageFitWizard.

Goal

A short, friendly quiz that helps visitors “See Which Package Fits You Best.” After submission, show a recommendation (Ignite/Growth/Scale), unlock the full pricing table, and provide clear CTAs to book a call or start an order.

Requirements
	•	Stack: React 18, TailwindCSS. No external UI libs.
	•	Form UX: single page with progressive disclosure (sections expand as user answers). Inline validation.
	•	Brand vibe: premium/minimal; deep navy background (#0B1220), white cards, large readable type (Inter). Cards have rounded-2xl, subtle shadows, micro-interactions (hover lift, focus rings).
	•	Performance: lightweight, no blocking assets; mobile-first; WCAG AA contrast.

Fields (with sample choices)
	1.	Business stage (radio): Solo / Growing team / Established
	2.	Timeline (radio): 7 days / 2–3 weeks / Flexible
	3.	Pages needed (multi or range): 1–3, 5–7, 8–12
	4.	Key features (checkbox):
	•	Lead capture (email opt-in / calendar link)
	•	Online bookings
	•	Payments/checkout
	•	Gated content / member area
	•	Blog + CMS
	5.	Copywriting help (radio): None / Some pages / Full site
	6.	SEO needs (radio): Basic (titles/meta) / Deeper (keywords/schema)
	7.	Budget comfort (radio): <$1K / $2–3.5K / $5–7K / Not sure
	8.	Contact (name, email, phone) — required to unlock results

Scoring → Tier Recommendation

Implement a simple rules engine:
	•	Ignite (Starter) when: pages ≤3, features ≤1 (no payments/bookings), copy help “none/ some,” SEO “basic,” budget “<$1K,” timeline “7 days.”
	•	Growth (Professional) when: pages 5–7 OR features include lead capture or blog; copy “some;” SEO “basic;” budget “$2–3.5K;” timeline “7 days / 2–3 weeks.”
	•	Scale (Premium) when: pages 8–12 OR features include bookings/payments/gated; copy “full site;” SEO “deeper;” budget “$5–7K;” timeline any.
	•	If mixed signals, choose the highest matching tier and mark others as “also fits.”
